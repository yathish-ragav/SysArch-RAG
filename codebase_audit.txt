# SysArch-RAG — Cursor AI Engineering Rules

## 1. Environment & Hardware Constraints (NON-NEGOTIABLE)
- OS: Ubuntu Linux on Asus Vivobook 16 (CPU-only, NO dedicated GPU).
- Python Package Manager: Always use `uv` (`uv add`, `uv run`), never raw `pip`.
- Embeddings: Use `fastembed` (ONNX CPU runtime) for `BAAI/bge-base-en-v1.5` (dense) and `Qdrant/bm25` (sparse). NEVER import `torch` or `sentence-transformers` for local GPU inference.
- Reranking: Use Cohere Rerank API (`rerank-v3.5` via `langchain-cohere`).
- LLM Inference: Use Groq API (`llama-3.3-70b-versatile` via `langchain-groq`).

## 2. Software Engineering & Architectural Standards
- Follow Spec-Driven Modularity: Never modify files outside the specific module requested in the prompt.
- Strict Contracts: Use Pydantic v2 (`BaseModel`, `BaseSettings`) for all data schemas, configurations, and LLM structured outputs. Zero untyped dicts between modules.
- Type Hints & Async: Every function must have complete Python 3.11+ type annotations. Use `async/await` for FastAPI, Qdrant (`AsyncQdrantClient`), and Redis (`redis.asyncio`).
- Dual Observability: Every LangChain/LangGraph call MUST attach both LangSmith (`LANGCHAIN_TRACING_V2=true`) and Langfuse Cloud (`langfuse.langchain.CallbackHandler`) callbacks.

## 3. RAG-Specific Guardrails
- Ingestion: Split strictly along Markdown headers (`#`, `##`, `###`). NEVER split inside fenced code blocks (```yaml, ```python, ```bash).
- Grounding: Every generated answer must include inline `[file_path § section]` citations or trigger a deterministic refusal when context score < 0.65.

# SysArch-RAG — Master Architecture & Execution Blueprint

## 1. Project Identity & Schedule
- **Project Name:** SysArch-RAG: Self-Correcting Cloud & Distributed Systems Intelligence Engine
- **Repository:** `sysarch-rag`
- **Schedule:** 5-Day Intensive Production Sprint (7–8 hours/day, ~35–40 hours total), starting Nov 25, 2026.
- **Role Split:** User is the **Lead Systems Architect** (defines boundaries, verifies traces, audits quality). AI is the **Senior AI Engineer & Code Verifier** (writes modular, type-safe, async Python/TypeScript code and flags edge-case failures).

## 2. Hardware & Environment Constraints (CRITICAL)
- **OS & Machine:** Ubuntu Linux on Asus Vivobook 16 (**CPU-only, no dedicated GPU**).
- **Mandatory Adaptations:**
  - **Embeddings:** Use `fastembed` (lightweight ONNX CPU runtime) for `BAAI/bge-base-en-v1.5` (dense) and `Qdrant/bm25` (sparse). Never load heavy PyTorch GPU models locally.
  - **Reranking:** Use **Cohere Rerank API (`rerank-v3.5`)** via `COHERE_API_KEY` instead of local GPU cross-encoders.
  - **LLM Synthesis:** Use **Groq API (`llama-3.3-70b-versatile`)** via `GROQ_API_KEY` for fast cloud inference.
  - **Fine-Tuning:** Run **Unsloth (QLoRA)** on **Google Colab free T4 GPU** on Day 3 to fine-tune `Qwen-2.5-Coder-7B` for relevance grading & JSON citations.

## 3. Complete Production Stack & Credentials Ready
- **Orchestration:** `LangGraph` (cyclic Corrective RAG state machine) + `LangChain` (Markdown/AST splitters).
- **Vector DB & Cache:** `Qdrant` (local Docker port `6333` for dev -> Qdrant Cloud for prod) + `Redis` (local Docker port `6379` for dev -> Upstash Redis for prod).
- **Dual Observability:**
  - **LangSmith** (`LANGCHAIN_API_KEY`, endpoint `https://langchain.com`) — traces LangGraph node transitions & hosts golden evaluation datasets.
  - **Langfuse Cloud** (`LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, host `https://langfuse.com`) — tracks p95 latency, token cost, and user feedback (cloud tier used to save ~1.5GB local RAM).
- **Evaluation ("Checking"):** `Ragas` + `DeepEval` enforced in GitHub Actions CI/CD (`Faithfulness >= 0.95`, `Context Recall >= 0.90`).
- **Backend & Frontend:** `FastAPI` (async SSE streaming + Redis semantic cache) + `Next.js 14` (or `Chainlit`) deployed on Render/Railway + Vercel.

## 4. Knowledge Base & Structure-Aware Ingestion
- **Sources (~400–600 official `.md` files via `git sparse-checkout`):**
  1. `kubernetes/website` (`content/en/docs/concepts` & `tasks`) -> `{service: "kubernetes", version: "1.31"}`
  2. `awsdocs/amazon-eks-user-guide` (`doc_source`) -> `{service: "aws-eks", version: "latest"}`
  3. `etcd-io/etcd` (`Documentation`) & `cncf/toc` -> `{service: "etcd-cncf", version: "v3.5"}`
- **Chunking Rules:** Split strictly on Markdown headers (`#`, `##`, `###`). Keep fenced code blocks (` ```yaml `, ` ```bash `, ` ```python `) 100% atomic—never split mid-block. Upsert both dense and BM25 sparse vectors to Qdrant with payload metadata indexes.

## 5. 7-Node LangGraph Corrective RAG (CRAG) Pipeline
1. `analyze_query`: Extracts metadata filters (`service`, `version`) and decomposes multi-part questions (Pydantic v2 structured output).
2. `hybrid_retrieve`: Queries Qdrant using Reciprocal Rank Fusion (RRF) across dense + sparse vectors (returns top 25 chunks).
3. `rerank_documents`: Calls Cohere `rerank-v3.5` to score top 25 chunks down to top 4 (`score >= 0.65`).
4. `grade_documents`: Evaluates if top 4 chunks sufficiently answer the query.
   - **Conditional Edge:** If insufficient AND `retry_count < 2` -> route to `rewrite_query` (broaden terms, relax filters, increment `retry_count`) -> loop back to `hybrid_retrieve`.
   - If insufficient AND `retry_count >= 2` -> route to `fallback_refusal` (deterministic refusal; zero hallucination).
5. `generate_answer`: Synthesizes grounded response with mandatory inline citations `[file_path § section]`.
6. `verify_hallucination`: Audits final output against retrieved chunks before streaming.

## 6. 5-Day Execution Roadmap
- **Day 1:** Folder & GitHub setup + Docker (`Qdrant` + `Redis`) + `fetch_docs.sh` + structure-aware Qdrant hybrid ingestion.
- **Day 2:** Cohere reranker + 7-node cyclic LangGraph pipeline + LangSmith & Langfuse dual tracing.
- **Day 3:** 50-question golden dataset + baseline Ragas metrics + Unsloth QLoRA fine-tuning on Colab + post-tuning Ragas comparison.
- **Day 4:** FastAPI streaming server + Redis semantic cache (`<80ms` repeat hits) + prompt-injection guardrails + GitHub Actions Ragas CI/CD gate.
- **Day 5:** Frontend chat UI with live agent reasoning trace + cloud deployment (Qdrant Cloud, Upstash, Render, Vercel) + README benchmarks.

from pathlib import Path
import shutil
import subprocess

RAW_DIR = Path("data/raw_docs")
TMP_DIR = Path("/tmp/sysarch_doc_clones")

REPOS = [
    {
        "name": "kubernetes",
        "owner": "kubernetes",
        "repo": "website",
        "paths": ["content/en/docs/concepts", "content/en/docs/tasks"],
    },
    {
        "name": "aws-eks",
        "owner": "awsdocs",
        "repo": "amazon-eks-user-guide",
        "paths": ["doc_source"],
    },
    {
        "name": "etcd-cncf",
        "owner": "etcd-io",
        "repo": "etcd",
        "paths": ["Documentation"],
    },
]


def run(cmd: list[str]) -> None:
    subprocess.run(cmd, check=True)


def main() -> None:
    if TMP_DIR.exists():
        shutil.rmtree(TMP_DIR)
    TMP_DIR.mkdir(parents=True)

    for item in REPOS:
        name = item["name"]
        url = "https://" + "github.com/" + item["owner"] + "/" + item["repo"] + ".git"
        clone_dir = TMP_DIR / name
        dest_dir = RAW_DIR / name

        if dest_dir.exists():
            shutil.rmtree(dest_dir)
        dest_dir.mkdir(parents=True)

        print(f"Fetching [{name}] from {url} ...")
        run(["git", "clone", "--depth", "1", "--filter=blob:none", "--sparse", url, str(clone_dir)])
        run(["git", "-C", str(clone_dir), "sparse-checkout", "set", *item["paths"]])

        for rel_path in item["paths"]:
            src = clone_dir / rel_path
            if src.exists():
                for md_file in src.rglob("*.md"):
                    target = dest_dir / md_file.relative_to(src)
                    target.parent.mkdir(parents=True, exist_ok=True)
                    shutil.copy2(md_file, target)

        md_count = len(list(dest_dir.rglob("*.md")))
        print(f"Saved {md_count} Markdown files for [{name}]")

    shutil.rmtree(TMP_DIR, ignore_errors=True)
    print("\nALL DOCS FETCHED SUCCESSFULLY!")


if __name__ == "__main__":
    main()

def get_langfuse_run_config(
    session_id: str | None = None,
    tags: list[str] | None = None,
) -> dict[str, Any]:
    configure_observability_env()
    Langfuse(
        public_key=settings.LANGFUSE_PUBLIC_KEY,

        metadata["langfuse_session_id"] = session_id
    return {"callbacks": [handler], "metadata": metadata}

import hashlib
from pathlib import Path
import re
from langchain_text_splitters import MarkdownHeaderTextSplitter
from src.core.schemas import DocMetadata, DocumentChunk

SERVICE_VERSIONS: dict[str, str] = {
    "kubernetes": "1.31",
    "aws-eks": "latest",
    "etcd-cncf": "v3.5",
}
MAX_CHUNK_CHARS = 2400
OVERLAP_CHARS = 250


def _strip_frontmatter(text: str) -> str:
    return re.sub(r"^---\s*\n.*?\n---\s*\n", "", text, count=1, flags=re.DOTALL)


def _split_preserving_code_blocks(text: str, max_chars: int = MAX_CHUNK_CHARS) -> list[str]:
    if len(text) <= max_chars:
        return [text.strip()] if text.strip() else []
    tokens = re.split(r"(```[\s\(\S\)]*?```)", text)
    chunks: list[str] = []
    current = ""
    for token in tokens:
        if not token.strip():
            continue
        is_code = token.startswith("```") and token.endswith("```")
        if is_code:
            if len(current) + len(token) > max_chars and current.strip():
                chunks.append(current.strip())
                current = token
            else:
                current = f"{current}\n\n{token}".strip()
        else:
            for para in token.split("\n\n"):
                para = para.strip()
                if not para:
                    continue
                if len(current) + len(para) + 2 > max_chars and current.strip():
                    chunks.append(current.strip())
                    tail = current[-OVERLAP_CHARS:] if not current.endswith("```") else ""
                    current = f"{tail}\n\n{para}".strip()
                else:
                    current = f"{current}\n\n{para}".strip()
    if current.strip():
        chunks.append(current.strip())
    return chunks


def chunk_markdown_file(file_path: Path, raw_root: Path) -> list[DocumentChunk]:
    rel_path = file_path.relative_to(raw_root)
    service_key = rel_path.parts[0]
    if service_key not in SERVICE_VERSIONS:
        return []
    clean_text = _strip_frontmatter(file_path.read_text(encoding="utf-8", errors="ignore"))
    if len(clean_text.strip()) < 80:
        return []
    splitter = MarkdownHeaderTextSplitter(
        headers_to_split_on=[("#", "h1"), ("##", "h2"), ("###", "h3")],
        strip_headers=False,
    )
    chunks: list[DocumentChunk] = []
    for doc in splitter.split_text(clean_text):
        parts = [doc.metadata[k] for k in ("h1", "h2", "h3") if doc.metadata.get(k)]
        section = " > ".join(parts) if parts else file_path.stem
        for idx, sub_text in enumerate(_split_preserving_code_blocks(doc.page_content)):
            if len(sub_text) < 60:
                continue
            ctx_text = f"[{service_key.upper()} | {rel_path.as_posix()} | {section}]\n{sub_text}"
            digest = hashlib.sha256(f"{rel_path.as_posix()}:{section}:{idx}".encode()).hexdigest()[:32]
            uid = f"{digest[:8]}-{digest[8:12]}-{digest[12:16]}-{digest[16:20]}-{digest[20:32]}"
            chunks.append(
                DocumentChunk(
                    chunk_id=uid,
                    content=ctx_text,
                    metadata=DocMetadata(
                        service=service_key,  # type: ignore[arg-type]
                        version=SERVICE_VERSIONS[service_key],
                        file_path=rel_path.as_posix(),
                        section_hierarchy=section,
                        has_code_block="```" in sub_text,
                    ),
                )
            )
    return chunks


def load_and_chunk_corpus(raw_root: Path = Path("data/raw_docs"), max_files_per_service: int = 150) -> list[DocumentChunk]:
    all_chunks: list[DocumentChunk] = []
    for service in SERVICE_VERSIONS:
        service_dir = raw_root / service
        if not service_dir.exists():
            continue
        md_files = sorted(service_dir.rglob("*.md"))[:max_files_per_service]
        service_chunks = [c for f in md_files for c in chunk_markdown_file(f, raw_root)]
        print(f"Chunked {len(md_files)} files -> {len(service_chunks)} chunks for [{service}]")
        all_chunks.extend(service_chunks)
    return all_chunks

import asyncio
from pathlib import Path
from fastembed import SparseTextEmbedding, TextEmbedding
from qdrant_client import AsyncQdrantClient, models
from src.core.config import settings
from src.core.schemas import DocumentChunk
from src.ingestion.chunker import load_and_chunk_corpus

DENSE_VECTOR_NAME = "dense"
SPARSE_VECTOR_NAME = "sparse"
DENSE_DIM = 768


async def ensure_hybrid_collection(client: AsyncQdrantClient, collection_name: str) -> None:
    if await client.collection_exists(collection_name):
        await client.delete_collection(collection_name)
    await client.create_collection(
        collection_name=collection_name,
        vectors_config={
            DENSE_VECTOR_NAME: models.VectorParams(size=DENSE_DIM, distance=models.Distance.COSINE)
        },
        sparse_vectors_config={
            SPARSE_VECTOR_NAME: models.SparseVectorParams(index=models.SparseIndexParams(on_disk=False))
        },
    )
    for field_name in ("service", "version", "has_code_block"):
        schema = models.PayloadSchemaType.BOOL if field_name == "has_code_block" else models.PayloadSchemaType.KEYWORD
        await client.create_payload_index(collection_name=collection_name, field_name=field_name, field_schema=schema)


async def index_chunks(chunks: list[DocumentChunk], batch_size: int = 32) -> None:
    print(f"Loading CPU ONNX models ({settings.DENSE_MODEL} & {settings.SPARSE_MODEL})...")
    dense_model = TextEmbedding(model_name=settings.DENSE_MODEL)
    sparse_model = SparseTextEmbedding(model_name=settings.SPARSE_MODEL)
    client = AsyncQdrantClient(url=settings.QDRANT_URL, api_key=settings.QDRANT_API_KEY)
    try:
        await ensure_hybrid_collection(client, settings.QDRANT_COLLECTION)
        total = len(chunks)
        for start in range(0, total, batch_size):
            batch = chunks[start : start + batch_size]
            texts = [c.content for c in batch]
            dense_vecs = list(dense_model.embed(texts))
            sparse_vecs = list(sparse_model.embed(texts))
            points = [
                models.PointStruct(
                    id=c.chunk_id,
                    vector={
                        DENSE_VECTOR_NAME: d.tolist(),
                        SPARSE_VECTOR_NAME: models.SparseVector(indices=s.indices.tolist(), values=s.values.tolist()),
                    },
                    payload={"content": c.content, **c.metadata.model_dump()},
                )
                for c, d, s in zip(batch, dense_vecs, sparse_vecs)
            ]
            await client.upsert(collection_name=settings.QDRANT_COLLECTION, points=points, wait=True)
            print(f"Indexed {min(start + batch_size, total)}/{total} chunks...")
        info = await client.get_collection(settings.QDRANT_COLLECTION)
        print(f"SUCCESS: Collection '{settings.QDRANT_COLLECTION}' live with {info.points_count} hybrid points.")
    finally:
        await client.close()


if __name__ == "__main__":
    chunks = load_and_chunk_corpus(Path("data/raw_docs"), max_files_per_service=150)
    asyncio.run(index_chunks(chunks, batch_size=32))

from functools import lru_cache
from fastembed import SparseTextEmbedding, TextEmbedding
from qdrant_client import AsyncQdrantClient, models
from src.core.config import settings
from src.core.schemas import DocMetadata, DocumentChunk, ScoredChunk
from src.ingestion.indexer import DENSE_VECTOR_NAME, SPARSE_VECTOR_NAME


@lru_cache(maxsize=1)
def get_dense_model() -> TextEmbedding:
    return TextEmbedding(model_name=settings.DENSE_MODEL)


@lru_cache(maxsize=1)
def get_sparse_model() -> SparseTextEmbedding:
    return SparseTextEmbedding(model_name=settings.SPARSE_MODEL)


def _build_filter(service: str | None = None, version: str | None = None) -> models.Filter | None:
    conditions: list[models.Condition] = []
    if service:
        conditions.append(models.FieldCondition(key="service", match=models.MatchValue(value=service)))
    if version:
        conditions.append(models.FieldCondition(key="version", match=models.MatchValue(value=version)))
    return models.Filter(must=conditions) if conditions else None


async def hybrid_search(
    query: str,
    top_k: int = 20,
    service_filter: str | None = None,
    version_filter: str | None = None,
) -> list[ScoredChunk]:
    dense_vec = next(get_dense_model().embed([query])).tolist()
    sparse_raw = next(get_sparse_model().embed([query]))
    sparse_vec = models.SparseVector(indices=sparse_raw.indices.tolist(), values=sparse_raw.values.tolist())
    q_filter = _build_filter(service=service_filter, version=version_filter)

    client = AsyncQdrantClient(url=settings.QDRANT_URL, api_key=settings.QDRANT_API_KEY)
    try:
        response = await client.query_points(
            collection_name=settings.QDRANT_COLLECTION,
            prefetch=[
                models.Prefetch(query=dense_vec, using=DENSE_VECTOR_NAME, filter=q_filter, limit=top_k),
                models.Prefetch(query=sparse_vec, using=SPARSE_VECTOR_NAME, filter=q_filter, limit=top_k),
            ],
            query=models.FusionQuery(fusion=models.Fusion.RRF),
            limit=top_k,
            with_payload=True,
        )
    finally:
        await client.close()

    results: list[ScoredChunk] = []
    for pt in response.points:
        payload = pt.payload or {}
        chunk = DocumentChunk(
            chunk_id=str(pt.id),
            content=payload.get("content", ""),
            metadata=DocMetadata(
                service=payload.get("service", "kubernetes"),
                version=payload.get("version", "1.31"),
                file_path=payload.get("file_path", ""),
                section_hierarchy=payload.get("section_hierarchy", ""),
                has_code_block=bool(payload.get("has_code_block", False)),
            ),
        )
        results.append(ScoredChunk(chunk=chunk, hybrid_score=float(pt.score)))
    return results

import asyncio
import cohere
import httpx
from src.core.config import settings
from src.core.schemas import ScoredChunk
from src.retrieval.hybrid_search import hybrid_search


async def rerank_chunks(
    query: str,
    candidates: list[ScoredChunk],
    top_n: int = 5,
) -> list[ScoredChunk]:
    if not candidates:
        return []

    async with httpx.AsyncClient(timeout=30.0) as http_client:
        co = cohere.AsyncClientV2(
            api_key=settings.COHERE_API_KEY,
            httpx_client=http_client,
        )
        response = await co.rerank(
            model=settings.RERANK_MODEL,
            query=query,
            documents=[c.chunk.content for c in candidates],
            top_n=min(top_n, len(candidates)),
        )

    reranked: list[ScoredChunk] = []
    for item in response.results:
        original = candidates[item.index]
        reranked.append(
            ScoredChunk(
                chunk=original.chunk,
                hybrid_score=original.hybrid_score,
                rerank_score=float(item.relevance_score),
            )
        )
    return reranked


async def _smoke_test() -> None:
    test_query = "How does etcd handle Raft leader election timeout and heartbeat interval?"
    candidates = await hybrid_search(test_query, top_k=15, service_filter="etcd-cncf")
    top_chunks = await rerank_chunks(test_query, candidates, top_n=3)
    for rank, sc in enumerate(top_chunks, start=1):
        print(f"#{rank} | rerank={sc.rerank_score:.4f} | rrf={sc.hybrid_score:.4f} | {sc.chunk.metadata.file_path} :: {sc.chunk.metadata.section_hierarchy}")


if __name__ == "__main__":

import asyncio
from langchain_core.messages import HumanMessage, SystemMessage
from langchain_groq import ChatGroq
from pydantic import BaseModel, Field
from src.core.config import settings
from src.core.schemas import Citation, GradeResult, QueryAnalysis, ScoredChunk
from src.graph.state import GraphState
from src.retrieval.hybrid_search import hybrid_search
from src.retrieval.reranker import rerank_chunks


def _fast_llm() -> ChatGroq:
    return ChatGroq(model=settings.GRADER_MODEL, api_key=settings.GROQ_API_KEY, temperature=0.0)


def _synthesis_llm() -> ChatGroq:
    return ChatGroq(model=settings.SYNTHESIS_MODEL, api_key=settings.GROQ_API_KEY, temperature=0.1)


async def analyze_query_node(state: GraphState) -> GraphState:
    query = state["query"]
    structured_llm = _fast_llm().with_structured_output(QueryAnalysis, method="json_mode")
    prompt = (
        "Return a JSON object with keys: "
        '"service_filter" ("kubernetes", "aws-eks", "etcd-cncf", or null), '
        '"version_filter" (string or null), and '
        '"sub_queries" (list of 1-2 focused technical search strings).'
    )
    try:
        analysis: QueryAnalysis = await structured_llm.ainvoke(
            [SystemMessage(content=prompt), HumanMessage(content=query)]
        )
        sub_queries = analysis.sub_queries[:2] if analysis.sub_queries else [query]
        svc = analysis.service_filter
        ver = analysis.version_filter
    except Exception:
        sub_queries, svc, ver = [query], None, None

    return {
        "active_query": query,
        "sub_queries": sub_queries,
        "service_filter": svc,
        "version_filter": ver,
        "retry_count": state.get("retry_count", 0),
    }


async def retrieve_and_rerank_node(state: GraphState) -> GraphState:
    queries = state.get("sub_queries") or [state.get("active_query", state["query"])]
    tasks = [
        hybrid_search(q, top_k=15, service_filter=state.get("service_filter"), version_filter=state.get("version_filter"))
        for q in queries
    ]
    batch_results = await asyncio.gather(*tasks)

    deduped: dict[str, ScoredChunk] = {}
    for chunk_list in batch_results:
        for sc in chunk_list:
            existing = deduped.get(sc.chunk.chunk_id)
            if existing is None or sc.hybrid_score > existing.hybrid_score:
                deduped[sc.chunk.chunk_id] = sc

    candidates = sorted(deduped.values(), key=lambda x: x.hybrid_score, reverse=True)[:20]
    reranked = await rerank_chunks(state.get("active_query", state["query"]), candidates, top_n=5)
    return {"reranked_chunks": reranked}


async def grade_documents_node(state: GraphState) -> GraphState:
    chunks = state.get("reranked_chunks", [])
    top_score = chunks[0].rerank_score if chunks and chunks[0].rerank_score is not None else 0.0
    if not chunks or top_score < settings.RERANK_SCORE_THRESHOLD:
        return {
            "grade_result": GradeResult(
                is_sufficient=False,
                confidence=float(top_score),
                reasoning=f"Top rerank score ({top_score:.2f}) below threshold ({settings.RERANK_SCORE_THRESHOLD}).",
            )
        }

    context_preview = "\n\n---\n\n".join(c.chunk.content[:900] for c in chunks[:3])
    grader = _fast_llm().with_structured_output(GradeResult, method="json_mode")
    grade: GradeResult = await grader.ainvoke(
        [
            SystemMessage(content='Return JSON with keys: "is_sufficient" (bool), "confidence" (float 0-1), "reasoning" (string).'),
            HumanMessage(content=f"Query: {state['query']}\n\nRetrieved Docs:\n{context_preview}"),
        ]
    )
    return {"grade_result": grade}


class _RewrittenQuery(BaseModel):
    rewritten_query: str = Field(description="Expanded technical search query")


async def rewrite_query_node(state: GraphState) -> GraphState:
    retry_count = state.get("retry_count", 0) + 1
    grade = state.get("grade_result")
    reason = grade.reasoning if grade else "Low relevance score"
    rewriter = _fast_llm().with_structured_output(_RewrittenQuery, method="json_mode")
    res: _RewrittenQuery = await rewriter.ainvoke(
        [
            SystemMessage(content='Return JSON with key "rewritten_query" expanding technical Kubernetes/AWS EKS/etcd terms.'),
            HumanMessage(content=f"Original query: {state['query']}\nFailure reason: {reason}"),
        ]
    )
    return {
        "active_query": res.rewritten_query,
        "sub_queries": [res.rewritten_query],
        "service_filter": None,
        "version_filter": None,
        "retry_count": retry_count,
    }


async def synthesize_answer_node(state: GraphState) -> GraphState:
    chunks = state.get("reranked_chunks", [])
    grade = state.get("grade_result")
    citations = [
        Citation(file_path=c.chunk.metadata.file_path, section=c.chunk.metadata.section_hierarchy, snippet=c.chunk.content[:220])
        for c in chunks[:4]
    ]
    if not chunks or (grade and not grade.is_sufficient and state.get("retry_count", 0) >= settings.MAX_RETRIES):
        return {
            "final_answer": "Insufficient verified documentation found in the indexed corpus to answer with high confidence.",
            "citations": citations,
        }

    formatted_ctx = "\n\n".join(
        f"[Source {i+1}: {c.chunk.metadata.file_path} | {c.chunk.metadata.section_hierarchy}]\n{c.chunk.content}"
        for i, c in enumerate(chunks[:5])
    )
    sys_msg = (
        "You are SysArch-RAG, a principal cloud infrastructure engineer. Answer strictly from context. "
        "Cite sources inline as `[file_path :: section]`. Preserve exact YAML/CLI flags."
    )
    ai_msg = await _synthesis_llm().ainvoke(
        [SystemMessage(content=sys_msg), HumanMessage(content=f"Question: {state['query']}\n\nContext:\n{formatted_ctx}")]
    )
    return {"final_answer": str(ai_msg.content), "citations": citations}

import asyncio
from langgraph.graph import END, START, StateGraph
from src.core.config import settings
from src.core.observability import get_langfuse_run_config
from src.graph.nodes import (
    analyze_query_node,
    grade_documents_node,
    retrieve_and_rerank_node,
    rewrite_query_node,
    synthesize_answer_node,
)
from src.graph.state import GraphState


def _route_after_grading(state: GraphState) -> str:
    grade = state.get("grade_result")
    retries = state.get("retry_count", 0)
    if grade and grade.is_sufficient:
        return "synthesize"
    if retries < settings.MAX_RETRIES:
        return "rewrite"
    return "synthesize"


def build_rag_graph():
    builder = StateGraph(GraphState)
    builder.add_node("analyze_query", analyze_query_node)
    builder.add_node("retrieve_and_rerank", retrieve_and_rerank_node)
    builder.add_node("grade_documents", grade_documents_node)
    builder.add_node("rewrite_query", rewrite_query_node)
    builder.add_node("synthesize", synthesize_answer_node)

    builder.add_edge(START, "analyze_query")
    builder.add_edge("analyze_query", "retrieve_and_rerank")
    builder.add_edge("retrieve_and_rerank", "grade_documents")
    builder.add_conditional_edges(
        "grade_documents",
        _route_after_grading,
        {"synthesize": "synthesize", "rewrite": "rewrite_query"},
    )
    builder.add_edge("rewrite_query", "retrieve_and_rerank")
    builder.add_edge("synthesize", END)
    return builder.compile()


rag_graph = build_rag_graph()


async def _smoke_test() -> None:
    run_cfg = get_langfuse_run_config(session_id="cli-smoke-test", tags=["module-4"])
    result = await rag_graph.ainvoke(
        {"query": "How do PodDisruptionBudgets protect workloads during a voluntary node drain in Kubernetes?"},
        config=run_cfg,
    )
    print(f"Retries: {result.get('retry_count', 0)} | Grade: {result.get('grade_result')}")
    print("\n--- ANSWER ---\n", result.get("final_answer"))


if __name__ == "__main__":
    asyncio.run(_smoke_test())
